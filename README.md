# КиОЭ ЛА — интерактивная методичка

Статическое веб-приложение по дисциплине «Конструкция и основы эксплуатации
летательных аппаратов» (УИ ГА). На главном экране — карта всех 14 тем курса;
полностью наполнена тема **«Сервоприводы»** (раздел 6, «Системы управления полётом»).

Ни сервера, ни базы данных: чистые HTML/CSS/JS. Хостится на GitHub Pages бесплатно.

## Как посмотреть локально

Открывать `index.html` двойным щелчком **нельзя** — браузер запретит читать
`content/*.json`. Нужен любой локальный сервер:

```bash
python -m http.server 5177
```

Затем открыть <http://127.0.0.1:5177/index.html>.

## Структура

```
index.html              каркас страницы
manifest.json, sw.js    PWA: «добавить на экран» и офлайн-доступ
assets/css/style.css    оформление (светлая тема, mobile-first)
assets/js/app.js        хэш-роутер, меню, загрузка тем
assets/js/render.js     блоки JSON -> DOM
assets/js/figures.js    интерактивные SVG-схемы
content/menu.json       карта всех 14 тем курса
content/servo-*.json    содержимое темы «Сервоприводы»
models/                 сюда кладутся .glb-модели (пока пусто)
tools/make_qr.py        генератор QR-кодов на каждый экран
```

## Как добавить новую тему

Код трогать не нужно.

1. В `content/menu.json` у нужной темы поменять `"status": "soon"` на `"ready"`
   и добавить массив `screens` со списком экранов.
2. На каждый экран создать `content/<id>.json`.
3. Готово — роутер подхватит их сам.

## Формат страницы

```json
{
  "id": "servo-booster",
  "crumb": "Тема 6 · Уровень 2",
  "title": "Заголовок",
  "lead": "Вводный абзац",
  "prev": { "id": "...", "title": "..." },
  "next": { "id": "...", "title": "..." },
  "blocks": [ ... ]
}
```

Типы блоков: `p`, `h2`, `h3`, `ul`, `ol`, `steps`, `table`, `src`,
врезки `fact` / `note` / `warn` / `key`, `figure`, `compare`, `quiz`.

Разметка внутри текста: `**жирный**`, `*курсив*`, `` `моно` ``,
`[[термин|всплывающее пояснение]]`.

## Интерактивные схемы

Регистрируются в `assets/js/figures.js` по имени и вызываются из JSON:

```json
{ "t": "figure", "name": "booster", "caption": "..." }
```

Доступны: `chain`, `direct`, `booster`, `feel`, `fbw`, `nws`.

Схемы шире экрана телефона прокручиваются вбок внутри своей рамки —
так подписи остаются читаемыми. Все бесконечные анимации сами
останавливаются, когда схема уходит с экрана.

## 3D-модели

Пока их нет; тема работает на 2D-анимациях. Когда появятся `.glb`
(экспорт из GPT Astra 6), их нужно положить в `models/` и добавить
в `figures.js` схему `model3d` на Three.js. Структура контента при этом
не меняется — достаточно заменить `"name": "booster"` на
`"name": "model3d"` с путём к файлу в `opts`.

## QR-коды

После публикации сайта:

```bash
pip install "qrcode[pil]"
python tools/make_qr.py https://ВАШ-ЛОГИН.github.io/servo-lab/
```

Скрипт создаст в `qr/` по одному коду на каждый экран — их можно
вставлять в бумажную методичку рядом с соответствующим разделом.

## Публикация на GitHub Pages

```bash
git remote add origin https://github.com/ВАШ-ЛОГИН/servo-lab.git
git branch -M main
git push -u origin main
```

Затем в репозитории: **Settings → Pages → Source: Deploy from a branch →
Branch: `main`, папка `/ (root)` → Save**. Через минуту сайт будет доступен
по адресу `https://ВАШ-ЛОГИН.github.io/servo-lab/`.

Файл `.nojekyll` в корне уже лежит — он нужен, чтобы GitHub Pages
отдавал файлы как есть.
