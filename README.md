# КиЛЭ ВС — интерактивная методичка

Статическое веб-приложение по дисциплине «Конструкция и лётная эксплуатация
воздушных судов» (УИ ГА им. Б. П. Бугаева). На главном экране — карта всех
14 тем курса; полностью раскрыта **глава 6 «Системы управления полётом самолёта»**
в восьми разделах.

Ни сервера, ни базы данных: чистые HTML/CSS/JS. Хостится на GitHub Pages бесплатно.

## Как посмотреть локально

Открывать `index.html` двойным щелчком **нельзя** — браузер запретит читать
`content/*.json`. Нужен любой локальный сервер:

```bash
python -m http.server 5177
```

Затем открыть <http://127.0.0.1:5177/index.html>.

## Структура

```
index.html              каркас страницы
manifest.json, sw.js    PWA: «добавить на экран» и офлайн-доступ
VISUALS.md              ТЗ на графику для GPT-6 — что и как визуализируем
assets/css/style.css    оформление (светлая тема, mobile-first)
assets/js/app.js        хэш-роутер, меню, отметки о прочитанном
assets/js/render.js     блоки JSON -> DOM
assets/js/figures.js    интерактивные SVG-схемы
content/menu.json       карта всех 14 тем курса
content/fc-*.json       содержимое главы 6
models/                 сюда кладутся .glb-модели (пока пусто)
tools/make_qr.py        генератор QR-кодов на каждый экран
```

## Как добавить новую тему

Код трогать не нужно.

1. В `content/menu.json` у нужной темы поменять `"status": "soon"` на `"ready"`
   и добавить массив `screens` со списком экранов.
2. На каждый экран создать `content/<id>.json`.
3. Готово — роутер подхватит их сам.

## Формат страницы

```json
{
  "id": "fc-booster",
  "crumb": "Глава 6 · Раздел 6.2",
  "title": "Заголовок",
  "lead": "Вводный абзац",
  "source": "Ссылка на первоисточник",
  "prev": { "id": "...", "title": "..." },
  "next": { "id": "...", "title": "..." },
  "blocks": [ ... ]
}
```

Типы блоков: `p`, `h2`, `h3`, `ul`, `ol`, `steps`, `table`, `stats`, `terms`,
`src`, врезки `fact` / `note` / `warn` / `key`, `figure`, `visual`, `compare`, `quiz`.

Разметка внутри текста: `**жирный**`, `*курсив*`, `` `моно` ``,
`[[термин|всплывающее пояснение]]`.

## Интерактивные схемы

Регистрируются в `assets/js/figures.js` по имени и вызываются из JSON:

```json
{ "t": "figure", "name": "booster", "caption": "..." }
```

Доступны: `chain`, `direct`, `comp`, `booster`, `feel`, `fbw`, `flap`, `nws`.

Схемы шире экрана телефона прокручиваются вбок внутри своей рамки — так подписи
остаются читаемыми. Все бесконечные анимации сами останавливаются, когда схема
уходит с экрана.

## Слоты под графику от GPT

Блок `visual` рисует пунктирную карточку с описанием будущей визуализации:

```json
{ "t": "visual", "id": "V-04", "kind": "3D-модель",
  "title": "Рулевой привод в разрезе", "brief": "..." }
```

Полное техзадание на все десять визуализаций — в [VISUALS.md](VISUALS.md).
Когда файл готов, слот меняется на реальную графику одной правкой JSON.

## QR-коды

После публикации сайта:

```bash
pip install "qrcode[pil]"
python tools/make_qr.py https://uiga-electronics.github.io/konstruktsiaVSiegoLE/
```

Скрипт создаст в `qr/` по одному коду на каждый экран.

## Публикация на GitHub Pages

Репозиторий: `UIGA-electronics/konstruktsiaVSiegoLE`.

Remote уже настроен, ветка `main`, история выровнена по `origin/main`.
Для отправки достаточно:

```bash
git push -u origin main
```

При первом пуше GitHub попросит авторизоваться — откроется окно входа
или запрос логина и токена.

Затем в репозитории: **Settings → Pages → Source: Deploy from a branch →
Branch: `main`, папка `/ (root)` → Save**. Через минуту-две сайт будет
по адресу <https://uiga-electronics.github.io/konstruktsiaVSiegoLE/>.

Файл `.nojekyll` в корне уже лежит — он нужен, чтобы GitHub Pages отдавал
файлы как есть.
